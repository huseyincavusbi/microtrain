# microtrain

Micro-scale training with macro-scale techniques.

Building a single MLX trainer that absorbs systems techniques from:
- [modded-nanogpt](https://github.com/KellerJordan/modded-nanogpt) — GPU systems & training speed
- [parameter-golf](https://github.com/openai/parameter-golf) — model compression & architecture density
- [slowrun](https://github.com/qlabs-eng/slowrun) — data efficiency & regularization

Full frozen copies of all three are in `reference/`
